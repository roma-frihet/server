# 실패 기록

에이전트가 저지른 실수를 남겨 같은 실수를 막는 곳입니다.

## 언제 쓰나

- 사용자가 결과물의 실수를 지적했을 때
- 훅이나 `check`가 같은 이유로 반복해서 막았을 때
- 장애나 데이터 문제로 이어질 수 있는 실수를 발견했을 때

## 어떻게 쓰나

`YYYY-MM-DD-짧은-설명.md` 파일을 만들고 아래 항목을 채웁니다.

```markdown
# 제목

- 요약: 무슨 일이 있었나
- 원인: 왜 그렇게 했나, 어떤 규칙이나 정보가 없었나
- 재발 방지: 무엇을 바꿨나
- 강제 수단: 검사 이름 또는 "문서만"
- 근거: 관련 파일, 로그, 테스트
```

## 승격 규칙

같은 원인이 두 번 나오면 문서로 끝내지 않고 검사로 바꿉니다. 구조 규칙은 ArchUnit, 코드 스타일은 detekt, 파일 및 명령 보호는 훅에 넣습니다.
